Methodology

Momentum

Uses only returned price/probability movement fields when available. If the API does not provide movement data, SignalDesk says so instead of inventing it.

Attention

Derived from returned volume, liquidity and trade/activity counts. Scores are relative to the current live market set and are not forecasts.

Risk & verification

Highlights market status, resolution timing and missing fields. SignalDesk is decision-support, not financial advice. Trading remains on Panta.
